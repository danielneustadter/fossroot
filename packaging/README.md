# Packaging

Everything needed to ship Fossroot on Linux (and eventually more). Status of
each format — see [docs/packaging.md](../docs/packaging.md) for the full
story and usage:

| Format | Where | Status |
|---|---|---|
| AppImage | [`appimage/`](appimage/) | **Built in CI** (`.github/workflows/package.yml`), attached to releases |
| Debian/Ubuntu `.deb` | `cargo deb` config in [`crates/fossroot/Cargo.toml`](../crates/fossroot/Cargo.toml) | **Built in CI**, attached to releases |
| RPM (Fedora/RHEL) | `cargo generate-rpm` config, same file | **Built in CI**, attached to releases |
| Arch AUR | [`aur/`](aur/) (`fossroot-git`) | Buildable PKGBUILD; not yet published to AUR |
| Nix flake | [`/flake.nix`](../flake.nix) | `nix run github:danielneustadter/fossroot`; untested pending a Nix host |
| Snap | [`snap/`](snap/) | Scaffold — needs classic confinement approval |
| Flatpak | [`flatpak/`](flatpak/) | Scaffold — sandbox can't write the host trust store (see manifest header) |
| Gentoo | [`gentoo/`](gentoo/) | Scaffold live ebuild; untested pending a Gentoo host |

Shared Linux desktop assets (desktop entry, AppStream metainfo) live in
[`linux/`](linux/) under the `com.fossroot.Fossroot` app ID; icons live in
[`assets/icon/`](../assets/icon/). Shell completions and man pages are
generated by the binary itself (`fossroot completions <shell>`,
`fossroot man`), so packagers never hand-maintain them.
